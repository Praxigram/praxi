## Get started

1. Install praxi:

   **Download:** [praxi for macOS](https://px.praxigram.com/download/macos). Open it and drag praxi to Applications.

   **Terminal:**

   ```sh
   curl -fsSL https://px.praxigram.com/install.sh | sh
   ```

   **Ask your agent:** paste this into Claude Code, Codex or the coding agent you use:

   ```text
   Help me install praxi on this Mac and learn to use it. Follow the "Start here" steps at https://px.praxigram.com/llms.txt. Show me each command and wait for my OK before you run it.
   ```

2. Install tmux if you don't have it yet: `brew install tmux`.
3. Open praxi and choose **Subscribe** to start your free trial. A payment method is required.
4. Open **Help → praxi Guide** to set up your first session.

Works on macOS 13 or later.

## What you get

- **Your agents in one window.** Give each agent its own terminal and see at a glance which are active and which are idle.
- **Several projects at once.** Work on different projects, or several features of one project, in parallel. Each session keeps its own terminals, open files, layout, prompts, scratchpad and notes, just as you left them.
- **See what your agents start.** tmux sessions your agents start in a praxi terminal show up as new tabs. Others wait under their project, one click on **Attach** away. The skill that comes with praxi teaches your agents how this works.
- **Agents keep running.** Sessions live in tmux, so your agents keep going after you quit praxi. Reopen it and they're right where you left them.
- **An editor for your prompts.** Write long prompts in Markdown and send them to the terminal you pick with ⌘↵.
- **Linked Markdown notes.** Keep plain .md notes that link to each other right next to the terminals they belong to.
